# Use Copilot to find guidance in the Implementation Portal

Copilot in the [Dynamics 365 Implementation Portal](https://aka.ms/D365ImplementationPortal) helps you find documentation and guidance for your Dynamics 365 and Power Platform implementation projects. [Microsoft Copilot](/copilot/overview) is a technology that understands natural language and provides relevant answers.

## How to use Copilot

To launch Copilot, look for the icon in the bottom right corner of any page in the [Dynamics 365 Implementation Portal](https://aka.ms/D365ImplementationPortal).

## What you can ask Copilot

Copilot in the Implementation Portal helps you find documentation and guidance about our products. It covers all the product documentation for Dynamics 365 and Power Platform, as well as Success by Design and other implementation guidance content.

For example, ask Copilot, `What's new this month for sales?`.

The Implementation Portal continues to expand on capabilities and related documentation to help you with your projects and related tasks.

## Use agents to profile and update your project

The Implementation Portal includes agentic capabilities that reduce the manual work for managing the project and improve the quality of your data. The agents review the documents that you upload, and then use them to keep your project record current with less manual effort.

The agents support two key activities:

- Profile the project by capturing products, capabilities, business processes, and characteristics.

- Update key project details, such as changes to the go-live date or the status of the current project.

Watch our [walkthrough video](https://youtu.be/h2ubYAvuuxM) for an end-to-end demonstration of how to access and use the agent functionality.

### Upload files for the agents to process

1. Go to the project record that you want to update.
1. In the **Implementation Copilot** section, select **Upload Files**.
1. Submit one or more documents, such as project plans, process documentation, or status updates. The agents support the following file formats: *.txt*, *.vtt*, *.pptx*, and *.pdf*.

After you submit a document, the agents review the content to derive relevant project information. You can view the agents' progress while they process the document.

### Review agent updates

When the agents finish, the updated values appear directly on the project record. Any field that an agent updates is highlighted with a visual indicator, so you can easily see what changed and review the new information.

### Use agents during onboarding

The agents are also available when you onboard a new project. In the profile step, you can upload documents to populate the project profile, which lets the agents establish project context from the start.

### Best practices for using agents

Keep the following best practices in mind as you use the agents:

- Always review recommendations before you accept them, and confirm that each update reflects the latest approved project information.

- Use the agents regularly as the project evolves, especially after major milestones, scope changes, or governance reviews.

- Remember that the agents are here to assist, but you remain responsible for confirming accuracy.

The agent functionality helps your team maintain better project data with less manual effort, keeping your implementation records current, consistent, and useful.
